添加模板

填写模板信息，右侧自动生成代码。复制后粘贴到 GitHub 的 js/data.js 里即可上线。

基本信息
预览与下载
点击「上传文件」：若上方已配置 GitHub，文件会传到仓库 previews/ 目录并回填直链（预览最稳定）；未配置则回退匿名托管。大文件建议仍用 R2 或网盘。
技术参数
描述
一键保存到 GitHub（免改代码）

配置一次后，点「直接入库」就会自动把这条模板写进仓库的 js/data.js，无需手动复制粘贴。

筛选标签管理（增删改首页筛选标签）

首页筛选面板的类型 / 风格 / 创作标签来自 js/data.js 的 FILTER_OPTIONS。在这里增删改后点「保存标签」，会直接写回仓库；添加模板表单里的类型 / 风格 / 创作下拉也会同步更新。

编辑 / 删除已有模板（后台管理）

一键加载仓库 js/data.js 中的模板列表，选中后自动回填左侧表单；修改任意字段（如预览视频 previewVideo、下载链接 downloadUrl）后点「保存修改」，或直接「删除该模板」。所有写入均通过 GitHub API 覆盖整份 js/data.js。
